# Libft

A collection of C utility functions written while learning the language at 42.

The repository contains two sets of exercises, including a 42-style Libft implementation in `libft_19/` and older standalone utility files at the repository root.

## Build

The Makefile for the main library is inside `libft_19/`.

```bash
cd libft_19
make
make bonus
```

This produces `libft.a`. The bonus target adds linked-list utilities.

## Contents

String and memory operations, character checks, conversions, output helpers and linked-list functions.

## What I learned

Reimplementing familiar C functions made pointer arithmetic, memory ownership and defensive argument handling much more concrete.

This is an educational library, not a general-purpose package.
